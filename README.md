# Bank Account Interest Calculator Demo App

Демо‑приложение для расчёта дохода по банковскому счёту.   
Проект демонстрирует применение архитектурного шаблона **MVVM**, библиотеки **ReactiveUI** и механизма внедрения зависимостей (**DI**) в десктоп‑приложении на C# с использованием фреймворка **Avalonia**.

## О проекте

Приложение создано для демонстрации профессиональных навыков разработки кроссплатформенных десктоп‑приложений.

## Ключевые возможности

* Расчёт дохода по банковскому счёту с учётом:
  * начальной суммы;
  * процентной ставки;
  * срока размещения (в месяцах и днях);
  * выбранного банка;
  * метода расчёта процентов.
* Выбор банка из списка с отображением фирменного цвета.
* Визуализация статуса операции (иконки успеха, ошибки, готовности).
* Ведение журнала расчётов с возможностью:
  * просмотра истории операций;
  * удаления отдельных записей;
  * очистки всего журнала.
* Автоматическое сохранение настроек приложения при закрытии окна.
* Валидация входных данных.
* Динамическое обновление даты окончания периода и количества дней в зависимости от метода расчёта.
* Интерактивный интерфейс с мгновенным обновлением результатов при изменении параметров.

## Технологии и инструменты

* **Язык программирования:** C#
* **UI‑фреймворк:** Avalonia (с использованием `Avalonia.Media`, `Avalonia.Platform`)
* **Архитектурный шаблон:** MVVM
* **Библиотека реактивного программирования:** ReactiveUI (включая `ReactiveUI.Avalonia`, `ReactiveUI.SourceGenerators`)
* **Внедрение зависимостей:** Microsoft.Extensions.DependencyInjection
* **Работа с коллекциями:** `ObservableCollection<T>` для динамического обновления UI
* **Реактивные расширения:** `System.Reactive` (операторы `WhenAnyValue`, `Throttle`, `ObserveOn`, `Subscribe`)
* **Платформа:** .NET (кроссплатформенное приложение)

## Особенности реализации

* Использование атрибута `[Reactive]` для автоматической генерации свойств с уведомлением об изменениях.
* Применение `ObservableAsPropertyHelper` для создания вычисляемых свойств.
* Управление командами через `ReactiveCommand` с динамическим определением возможности выполнения.
* Использование `Interaction<TInput, TOutput>` для диалогов.
* Подписка на изменения свойств через `WhenAnyValue` с применением `Throttle` для оптимизации.
* Сохранение и загрузка настроек приложения (`AppSettings`).
* Логирование расчётов (`CalculationLogEntry`).
* Отображение статуса операций с иконками (SVG).
